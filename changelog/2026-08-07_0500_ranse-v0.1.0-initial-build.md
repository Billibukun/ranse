# 2026-08-07 — Ranse v0.1.0: initial build

**Branch:** main · **Repo:** https://github.com/Billibukun/ranse (created this session)

## Shipped

- Named the product **Ranse** (Yoruba *ránṣẹ́* — "send word"). Package
  `com.datadruid.ranse`, launcher label "Ranse".
- Full Flutter Android MVP (`app/`), all files ≤400 lines:
  - Account setup with cPanel auto-discovery (`mail.<domain>` → bare domain;
    IMAP 993 SSL / 143 STARTTLS; SMTP 587 STARTTLS / 465 SSL — probes by real
    login), plus manual-override form.
  - Inbox (envelope fetch, newest first, pull-to-refresh), message view
    (HTML via flutter_widget_from_html_core, attachments open via open_filex),
    compose/reply/reply-all/forward with attachments, send with append-to-Sent.
  - Multi-account; credentials in flutter_secure_storage (Keystore-backed).
  - New-mail notifications: workmanager 15-min poll comparing stored uidNext
    watermark per account; caps at 5 notifications + summary.
  - OTA auto-update: checks GitHub Releases `releases/latest`, semver compare,
    downloads APK, launches installer (REQUEST_INSTALL_PACKAGES).
  - Light default + dark mode toggle (SegmentedButton in Settings), persisted;
    system honoured until explicit choice.
- Release signing: `ranse-release.jks` (30-yr validity) + `key.properties`,
  both gitignored; uploaded to repo secrets `ANDROID_KEYSTORE_BASE64`,
  `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
- CI: `.github/workflows/release.yml` — tag `v*` → analyze + test + signed
  APK → GitHub Release (auto notes).
- Tests: `Updater.isNewer` semver unit tests. `flutter analyze` clean.

## Decisions

- Polling now, push bridge later: the Hetzner IMAP-IDLE→FCM bridge (see
  `docs/design.md`) is the phase-2 replacement for the 15-min poll.
- Repo is **public** so unauthenticated update checks and APK downloads work.
- Project lives in `Desktop\apps\webmail` — Ibukun explicitly overrode the
  no-Desktop rule for this repo (OneDrive will sync it).
