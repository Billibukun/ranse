**Branch:** main · **Tag:** v0.2.0 (CI-built release)

## Design process (design/ folder)

- Built a local design-review experience: `design/server.py` (port 7420,
  CORS, POST /save, auto-reload) + `design/index.html` - brief form + 4
  directions x 10 phone-mockup screens (A Ivory Post, B Signal, C Sunbird,
  D Ledger) with per-screen A/B/C/D selection.
- Round 1 picks: signin A, inbox C, drawer/read/reply/compose/actions/empty D,
  search C, settings A. Brief: professional+premium, compact, NO avatars,
  inline reply, glassmorphism + centered glass bottom bar, no gradients,
  rounded corners, accent left open (proposed ink-green #175244 + brass
  #A8874C - accepted implicitly).
- Round 2 synthesis (dR) appended; verdict notes: text never jumbled,
  attachments present well, layout premium. Raw data:
  `design/design-feedback.json` (+ `.round1.json`), brief:
  `design/design-brief.json`.
- Gotcha: Ibukun opened the page via file:// and Chrome Save-As drops form
  state - recovery = localStorage + CORS'd absolute save URL. Keep server.py
  running for any future rounds.

## Shipped (app v0.2.0)

- Design system: `theme.dart` rewritten - RanseColors ThemeExtension,
  Fraunces (brand) + Archivo (UI) via google_fonts, Glass + RanseCard
  widgets, full light AND dark themes.
- Folders: `MailService.listFolders()` resolves Inbox/Sent/Drafts/Junk/
  Trash/Archive by SPECIAL-USE flags with name fallbacks; any folder
  openable; drawer (`ranse_drawer.dart`) has account switcher + folder list
  with counts.
- Glass bottom bar (`glass_bar.dart`): Inbox/Sent/Drafts + Compose.
- Inbox: greeting header, dense no-avatar rows (`message_row.dart`),
  long-press multi-select -> archive/junk/trash via glass action header.
- Message view: meta card, HTML body, tappable attachment chips with sizes,
  toolbar archive/junk/trash, INLINE glass reply pane with rich text.
- Rich text: flutter_quill 11.5.1 (`rich_composer.dart` + custom B/I/U
  FormatBar) -> multipart/alternative (plain + HTML via
  vsc_quill_delta_to_html ConverterOptions.forEmail).
- Search screen: server-side IMAP search, unread filter, people strip.
- Settings + sign-in restyled (segmented theme control, glass card).

## Build gotchas (this session)

- flutter_quill needs `intl: 0.20.2` exactly (flutter_localizations pin);
  11.0.0 breaks on Flutter 3.44 (TextInputClient.onFocusReceived) - use
  ^11.5.1.
- **OneDrive locks `app/build/` intermediates** and kills local gradle
  builds (Unable to delete directory). CI (Linux, no OneDrive) is the
  reliable channel. Local builds: retry after OneDrive settles, or move the
  repo out of OneDrive.
